# PunPun (ปันปัน) - Donation & Swap Community App 🎁

## 📌 เกี่ยวกับแอปพลิเคชัน (About)
PunPun เป็นแอปพลิเคชันชุมชนสำหรับการบริจาคและแลกเปลี่ยนสิ่งของ เพื่อช่วยเหลือสังคมในยามวิกฤต (เช่น สถานการณ์ COVID-19) และเป็นพื้นที่พบปะสำหรับผู้ที่ต้องการแลกเปลี่ยนของในสถานการณ์ปกติ โดยเน้นความปลอดภัยและความโปร่งใสของผู้ใช้งานเป็นหลัก

## 🚀 ฟีเจอร์หลัก (Key Features)
- **Secure Authentication:** ระบบสมาชิกที่รัดกุม พร้อมการยืนยันตัวตนด้วยบัตรประชาชน (KYC) ในขั้นตอนการสมัคร
- **Give / Request / Swap:** ระบบโพสต์ "ให้ / ขอรับ / แลก" สิ่งของ พร้อมรูปภาพและรายละเอียด (สภาพ, ขนาด, ยี่ห้อ)
- **Post Expiration:** สามารถตั้งระยะเวลาหมดอายุของโพสต์ได้ (สูงสุดไม่เกิน 7 วัน)
- **Smart Feed & Search:** หน้า Timeline ที่สามารถค้นหาและกรองข้อมูลตามหมวดหมู่สินค้าและประเภทโพสต์ได้อย่างแม่นยำ
- **In-App Chat & Push Notifications:** ระบบสนทนาระหว่างสมาชิกแบบเรียลไทม์ และแจ้งเตือนเมื่อมีผู้สนใจหรือทักแชท
- **Trust Score:** ระบบคะแนนความน่าเชื่อถือของผู้ใช้งานแต่ละราย เพื่อป้องกันมิจฉาชีพ
- **Top Donors Ranking:** ระบบจัดอันดับผู้บริจาคสูงสุดเพื่อเชิดชูเกียรติ

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)
- **Frontend:** Flutter (Dart)
- **Backend/Database:** Firebase (Firebase Auth, Cloud Firestore, Firebase Storage)
- **UI/UX:** Custom Design Theme (สีฟ้า `#2563EB`) พร้อมรองรับ Google Fonts (Kanit)

## 📦 การติดตั้งและรันโปรเจกต์ (How to Run)
1. Clone โปรเจกต์นี้ลงในเครื่อง
2. รันคำสั่ง `flutter pub get` เพื่อติดตั้ง Packages ทั้งหมด
3. รันคำสั่ง `flutter run` เพื่อทดสอบแอปพลิเคชันบน Emulator หรือ Physical Device
